## `02 / FEATURED SYSTEMS`

> 🔒 **Note:** These projects are owned by companies/partners and kept in private repositories. Only the technical approach and my role are described — no confidential details.

### 🍱 AI-Powered Digital Platform for the F&B Industry

A complete web ecosystem for an F&B business — brand website, multi-channel customer support system, and an internal operations dashboard.

**Role:** Fullstack Developer — owned the entire frontend (Next.js), built the backend APIs (Node.js), integrated the AI Agent, and developed the realtime layer.

| Technical solution | Description |
| :--- | :--- |
| **Realtime system** | Staff dashboard with queue management, connection-state handling via SignalR, multi-tier notifications (Desktop / Audio / Visual) |
| **AI Agent integration** | Multilingual AI assistant (RAG), multimodal image processing, invoice data extraction, automated Telegram/Email notifications |
| **Performance** | Modern Bento UI, image optimization + caching, PageSpeed > 90 on all devices |

**Impact:**
- Automated ~60–70% of common customer requests
- Cut response time from minutes to seconds
- Removed the language barrier for international customers

**Stack:** `Next.js` · `React` · `Node.js` · `SignalR` · `AI RAG` · `MongoDB` · `Redis` · `Docker`

<br />

### 🎨 Personal Portfolio — Bento Grid, Near-Perfect Performance

A personal portfolio built in the Bento Grid style, multilingual, with near-perfect performance scores.

**Role:** Designed & built everything — from UI concept to production deployment on Vercel.

| Technical solution | Description |
| :--- | :--- |
| **Bento Grid layout** | Responsive grid that adapts to every screen size |
| **Core Web Vitals** | Lighthouse 95–100, LCP < 0.8s via Static Site Generation |
| **Micro-interactions** | Spotlight effects, fluid motion with Framer Motion |
| **i18n** | Instant EN ↔ VI switching, no page reload |

**Stack:** `Next.js` · `React` · `TypeScript` · `Tailwind CSS` · `Framer Motion`

🔗 **Live:** [nguyenminhhuy-portfolio.vercel.app](https://nguyenminhhuy-portfolio.vercel.app/)
